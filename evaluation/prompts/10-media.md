# 10 媒体类组件

- 阶段：10 / 15
- 目标：覆盖 `Image`、`Icon`、`Video`、`AudioPlayer`
- 自动执行：

```bash
node evaluation/run-case.mjs 10-media
```

## 发给 AI 的提示词

```text
生成一个媒体展示页面，包含一张封面图、一个播放图标、一个视频播放器和一个音频播放器，每部分配一个标题。
```

## 预期协议

- `Image`：封面图，带 `url` / `altText` / `fit`
- `Icon`：播放图标
- `Video`：视频地址
- `AudioPlayer`：音频地址与描述
- 每个媒体组件都配一个 `Text` 标题

## 检查项

- [ ] 四种媒体组件都存在
- [ ] 每个媒体都有标题
- [ ] 图片有 `altText`
- [ ] 没有使用未定义组件
- [ ] 预览渲染不报错
- [ ] 媒体 URL 使用合法的 https 地址

| 项 | 分值 |

## 说明

示例媒体 URL 在部分网络环境可能加载失败，这属于网络问题，不算协议错误。
