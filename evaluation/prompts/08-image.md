# 08 图片输入（多模态）

- 阶段：8 / 9
- 目标：验证图片理解与布局还原
- 执行方式：手工

## 操作步骤

1. 准备一张页面截图或设计稿
2. 在 Playground 点击「添加图片」
3. 选择图片（最多 4 张）
4. 输入下面的提示词并发送

## 发给 AI 的提示词

```text
请参考这张图片还原一个页面，保持布局和主要文案。
```

也可以补充：

```text
请优先还原结构：顶部标题、中间卡片、底部按钮；配色接近原图即可，不需要逐像素还原。
```

## 预期协议

- 使用 `Column` 组织上下区块
- 使用 `Card` / `Row` 承载卡片内容
- 主要文案以 `literalString` 输出
- 图片位置对应 `Image` 组件
- 不要编造图中不存在的数据

## 检查项

- [ ] 区块数量与图片基本一致
- [ ] 主要文案与图片一致
- [ ] 组件类型与视觉元素匹配
- [ ] 没有明显遗漏核心区块
- [ ] 没有编造文案
- [ ] 模型确实接收到了图片（不是纯文本生成）

## 评分

| 项 | 分值 |
| --- | --- |
| 布局还原 | 30 |
| 文案还原 | 20 |
| 组件正确 | 20 |
| 协议合法 | 20 |

## 说明

能否真正“看懂”图片取决于模型是否具备视觉能力。

如果使用纯文本模型，本用例应记录为：

```text
模型不支持视觉输入，无法评测图片理解
```
