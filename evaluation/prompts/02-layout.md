# 02 布局组件

- 阶段：2 / 9
- 目标：验证 `Row` / `Column` 与 `children.explicitList`
- 自动执行：

```bash
node evaluation/run-case.mjs 02-layout
```

## 发给 AI 的提示词

```text
生成一个横向排列的顶部导航，左边是标题「我的应用」，右边是两个按钮「登录」和「注册」。
```

## 预期协议

- 根节点通常是 `Row`
- 使用 `children.explicitList` 引用子组件
- 包含 `Text` 与两个 `Button`
- 可以通过嵌套 `Row` 实现左右分区

## 检查项

- [ ] 根节点是 Row（或等价横向容器）
- [ ] 标题在左，按钮在右
- [ ] 两个按钮都存在
- [ ] 子组件 id 都被正确引用
- [ ] 预览横向排列，没有纵向堆叠
- [ ] 没有使用未注册组件

## 评分

| 项 | 分值 |
| --- | --- |
| 协议合法 | 25 |
| 组件正确 | 20 |
| 布局还原 | 20 |
| 渲染正确 | 15 |

## 常见失败

- 所有组件平铺在 Column 里
- 忘记写 `children.explicitList`
- 引用不存在的子组件 id
