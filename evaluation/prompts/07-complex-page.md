# 07 复杂页面

- 阶段：7 / 9
- 目标：验证多区块、多组件组合与信息层级
- 自动执行：

```bash
node evaluation/run-case.mjs 07-complex-page
```

## 发给 AI 的提示词

```text
生成一个天气页面，包含当前城市、温度、天气状况、未来三天预报和刷新按钮。
```

## 预期协议

- 根节点为 `Column`
- 当前天气区块使用 `Card` / `Row`
- 包含 `Text`、`Icon`、`Button`
- 未来三天可以使用 `List.children.template`
- 数据可以通过 `dataModelUpdate` 提供

## 检查项

- [ ] 城市、温度、天气状况都存在
- [ ] 未来三天都有预报
- [ ] 刷新按钮存在
- [ ] 信息层级清晰：当前天气 → 预报 → 操作
- [ ] 组件数量合理，没有过度嵌套
- [ ] 预览布局稳定，没有明显重叠

## 评分

| 项 | 分值 |
| --- | --- |
| 协议合法 | 20 |
| 组件正确 | 20 |
| 布局还原 | 20 |
| 数据绑定 | 10 |
| 渲染正确 | 15 |

## 常见失败

- 只生成当前天气，缺少未来三天
- 所有内容平铺，没有分组
- 图标名不在支持列表中
- 组件 id 冲突
